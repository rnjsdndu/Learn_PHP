# Database (DB)

## DBMS (Database Management System)
  #### DB를 관리하는 시스템을 DBMS라고 부릅니다.
  #### DBMS로 유명한 것들은 Oracle, MSSQL, MySQL 등이 있습니다.

## SQL
  #### DBMS에서 데이터를 뽑아오거나 입력하는 등의 작업을 하는 언어입니다.

## SQL로 할 수 있는 것들
 #### - DB의 생성, 수정, 삭제
 #### - Table의 생성, 수정, 삭제
 #### - Row의 추가, 수정, 삭제
 #### - 조회, 검색
